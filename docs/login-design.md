# Login — dirección visual

Acceso cotidiano de profesionales a Espacio TO. El usuario prefirió recuperar la calidez del primer diseño con menos información.

## Sistema visual

- Blanco #ffffff para el acceso.
- Salvia #eaf2ec para la bienvenida.
- Verde #376b53 para acentos y acciones secundarias.
- Tinta #20313a para texto principal.
- Pizarra #626f77 para texto secundario.
- Borde #d7dfe3 para controles.

Pila de sistema, título de acceso 30 px, texto de 15 px e información secundaria de 13 px. La bienvenida tiene un título de 30–42 px sin palabras resaltadas ni etiquetas adicionales.

## Composición elegida

Dos paneles con una única función cada uno. Bienvenida a la izquierda; acceso a la derecha, alineado a la izquierda dentro de un bloque de 360 px.

    Espacio TO                      Ayuda
    Terapia ocupacional

    Un espacio para                 Bienvenido
    acompañar.                      Instrucción breve
    [planta sencilla]               [Continuar con Google]
                                    Uso de nombre y correo

    © Espacio TO                    Privacidad

La ilustración de una planta recupera el motivo de crecimiento del primer diseño. Se retiraron las notas flotantes, los eslóganes adicionales, los adornos de fondo y el bloque repetido de seguridad. En celular el panel de bienvenida se reduce a la marca y el formulario conserva el protagonismo.

## Revisión

Comprobar escritorio, tablet y celular desde 320 px, foco visible y diálogo de ayuda. Mantener el botón oficial de Google, la sesión y la revocación al cerrar sesión.
